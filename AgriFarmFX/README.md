# AgriFarm FX — JavaFX Livestock Management
----------------------------------------------------------------------------------------------------------------------------------------------------------------
## চালানোর ধাপ (VS Code / IntelliJ)
1. JDK 17+ ইনস্টল করুন (`java -version` দিয়ে চেক করুন)
2. Maven ইনস্টল করুন (`mvn -v` দিয়ে চেক করুন)
3. প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে লিখুন:  `mvn javafx:run`

ডেটা সেভ হয়: `~/.agrifarm/data.json`
